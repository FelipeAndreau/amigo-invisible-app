# Script de Video - Felipe Andreau

**Tema**: Infraestructura, Estructura del Proyecto y Backend base.

**Guion Sugerido**:
"Hola, soy Felipe. Mi rol en esta primera entrega fue sentar las bases técnicas del proyecto. Configuré el entorno usando **Expo SDK 54**, que es la versión más estable para 2026, asegurando que la app sea rápida y moderna. 

Organicé el código bajo el patrón **Package-by-Feature**, lo que significa que el código está ordenado por funcionalidades y no por carpetas técnicas, facilitando el trabajo en equipo. Además, dejé listo el servidor en **Golang** usando el framework **Gin**. Aunque esta fase es offline, ya tenemos la estructura profesional de backend preparada en la nube para las próximas entregas."
