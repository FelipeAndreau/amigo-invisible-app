# Índice de Temas - IA Entrega 2

Este documento cataloga las habilidades y consultas realizadas a la IA durante el desarrollo de la E2.

## Habilidades de IA Utilizadas
- **Architectural Scaling:** Diseño de la transición de estado local a arquitectura cliente-servidor.
- **Security Engineering:** Implementación de flujos JWT y Magic Links para privacidad.
- **RESTful Design:** Definición de contratos de API para gestión multi-entidad.
- **Documentation Management:** Generación de documentos de alcance y técnicos bajo estándares académicos.

## Registro de Consultas Clave
1. "Cómo escalar una app de Amigo Invisible de local a online manteniendo la privacidad".
2. "Mejor estrategia para Magic Links de un solo uso en Go".
3. "Esquema de base de datos para múltiples sorteos por usuario".
4. "Implementación de Auth Middleware en Gin Gonic".
